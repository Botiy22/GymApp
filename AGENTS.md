# GymApp development

Use the exercise guide schema in EXERCISE_GUIDE.md for every new or modified exercise.
Preserve exercise IDs, existing plans, diary data, storage keys, backups and cloud sync.
Keep source uncertainty explicit. Do not invent nutrition or measured muscle activation.
Use two detailed static movement positions with normal faces; no stock human-photo animations
or video links in exercise detail views. Keep HU/EN instructions short and variation-specific.
Communicate in Hungarian. Do not add or run tests unless the user explicitly requests them.
Report source review, syntax checks and runtime/layout checks separately and honestly.
Never force push. Merge only completed work, preserving concurrent main changes.
